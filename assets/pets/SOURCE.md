# Imported pet artwork

Three spritesheets are copied unchanged from the audited repositories. Playback is adapted for T3 Pet. Offline shares idle; working uses row 7, waiting row 6, error row 5, and completion uses jumping row 4. Idle uses row 0. The adapter excludes padding cells and uses local task timings for Codex Pet Collection; lencx timings are preserved. No image generation or pixel edits were performed.
