# LFG Pet assets

Source: https://github.com/SpyC0der77/lfg-codex-pet
Commit: 60716f8273e4a69b40dace98b241ab5c23733217

The user confirmed that they created this artwork and requested its use in T3 Pet.
These seven PNG sprite sheets are copied unchanged from the repository's outputs directory.
Frame durations are transcribed from the corresponding src generators.

Typing: [20, 40 x 47, 20] ms. Needs input: [30, 60 x 47, 30] ms.
Ready: [40, 80 x 47, 40] ms. Broken: [20, 50 x 47, 30] ms.
Jumping and walking: 16 frames at 80 ms. Emotion sheets: 7 x 7 cells of 128 x 128.
Movement sheets: 8 x 2 cells of 192 x 208.

App and tray icons use a separate paw mark from assets/icon.svg. Builds preserve the pet artwork independently of app branding.
